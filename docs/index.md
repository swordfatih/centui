# CentUI

CentUI helps you build a C++ interface out of text, buttons, inputs, images, and containers. Widgets form a tree. You can build that tree in one expression or add children as your application runs.

The Studio examples show the two approaches side by side: [nested construction](https://github.com/swordfatih/centui/blob/main/examples/gui_static/main.cpp) and [dynamic construction](https://github.com/swordfatih/centui/blob/main/examples/gui_dynamic/main.cpp).

Start with [Getting Started](getting-started.md). Then read [Widgets and Styles](widgets-and-styles.md), [Extending CentUI](extending.md), or [Backends and Windows](backends.md) when you need them.
