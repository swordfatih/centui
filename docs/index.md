# Build an interface, one idea at a time

CentUI lets you write an interface as a tree of C++ widgets. Give the widgets named styles, connect them to application state, and render them in your own loop.

Start with a working app. Each guide adds something you can use in the next one.

| Guide | You will learn to |
| --- | --- |
| [1. Your first app](getting-started.md) | Open a window and make a button update a label. |
| [2. Widgets and styles](widgets-and-styles.md) | Compose reusable appearances and arrange a page. |
| [3. State and interaction](interaction.md) | Connect controls, change a tree, and manage ownership. |
| [4. Text and fonts](text.md) | Choose fonts and work with editable text. |
| [5. An existing application](backends.md) | Add a UI without giving up your scene or event loop. |
| [6. Custom widgets](extending.md) | Measure, draw, and animate your own control. |
